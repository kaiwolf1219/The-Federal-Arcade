# The-Federal-Arcade
THE FEDERAL ARCADE is an AI-assisted vibe-coding project: an independent political satire arcade built with HTML, CSS, and JavaScript. I developed the concept and direction, then iterated on the games and site until it was ready to play. It currently includes Snake on the Hill and Executive Orders, with high scores saved in the player’s browser.
